# Hey! 👋 I'm Richard

I've been building local-first AI tools and fast developer software — things that run on your machine, not in someone else's cloud.

## What I'm building

- **[Whisper Dictate](https://github.com/rorshopping/whisper-dictate-releases)** — local, offline push-to-talk dictation for Windows, macOS and Linux
- **[openrobots](https://openrobots.vercel.app)** — 🤖 decide how AI sees your site: free, open-source robots.txt & llms.txt generator for 80+ AI crawlers, no signup, 100% in-browser
- **[jev-on-a-laptop](https://github.com/rorshopping/jev-on-a-laptop)** — Jev-style parallel typed decisions on stock 1.5B–8B models on an Apple Silicon laptop: benchmarks, research notes, and a Hugging Face Space demo
- **[parallel-decisions](https://github.com/rorshopping/parallel-decisions)** — typed, locally-run LLM decisions on Apple Silicon: context + schema in, typed answers with probabilities out, one batched forward pass

## My current focus

On-device AI — making local models fast and reliable enough to leave the cloud behind.
